# KONTUR Ledger CRM / KONTUR 纸感 CRM

Swiss-ledger CRM workspace on warm paper: pipeline kanban, contact ledger, pure-CSS revenue chart, and an activity timeline.

A standalone Next.js + Tailwind CSS v4 project exported from
[StyleKit Templates](https://www.stylekit.top/templates).

## Getting started / 快速开始

```bash
pnpm install   # or: npm install / yarn
pnpm dev       # http://localhost:3000
```

## Stack

- Next.js (App Router) + React
- Tailwind CSS v4 (no config file needed)
- lucide-react icons
